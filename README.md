# ESSENTIAL LUXE - Premium Import Preorder Platform

Bridging Continents, Delivering Distinction. A modern, luxury minimalist logistics system for China and USA imports.

## Features
- **Luxury Aesthetic:** Minimalist design with black, white, and gold accents.
- **6-Step Order Flow:** Guided request process for users.
- **Real-time Status:** Track orders through Pending, Processing, Shipped, and Delivered states.
- **Email Notifications:** Automatic alerts to the business owner on new submissions.
- **Secure Auth:** NextAuth.js integration for user accounts.
- **Responsive:** Mobile-first design for all devices.

## Tech Stack
- **Frontend:** Next.js 15, TypeScript, Vanilla CSS (CSS Modules)
- **Backend:** Next.js API Routes, Node.js
- **Database:** MongoDB (Mongoose)
- **Authentication:** NextAuth.js
- **Email:** Nodemailer
- **Animations:** Framer Motion

## Getting Started

1. **Clone the repo**
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Configure Environment:**
   Copy `.env.example` to `.env.local` and fill in your credentials:
   - MongoDB URI
   - NextAuth Secret
   - Cloudinary API details
   - SMTP Email details
4. **Run development server:**
   ```bash
   npm run dev
   ```
